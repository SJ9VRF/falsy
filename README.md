## Design direction

This version deliberately avoids a neon / crypto / generic AI-startup look. It uses:

- editorial serif headline typography
- restrained off-white / black palette
- one muted violet accent
- more whitespace
- fewer decorative icons
- evidence-first hierarchy
- dense technical detail only after the recruiter-facing sections

## Public deployment

The site is ready for GitHub Pages, Netlify, Vercel, or a personal domain. A public GitHub repository URL is intentionally **not fabricated**. Once the repo is published, replace the code archive CTA with the real repository link.
